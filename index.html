LOGIC AI 8.2 · EMBODIED ACTION + KNOWLEDGE

⚙️ Logic Action Model 1.2

Carga un HTML como entorno. Logic no ejecuta JavaScript generado como “cerebro”: produce acciones estructuradas (CLICK, KEY_DOWN, TYPE, SCROLL, TOUCH, DRAG, WAIT, READ_STATE) y un Executor aislado las traduce a eventos del entorno.

Strict es el modo recomendado. “Compatible” mejora la compatibilidad de juegos que dependen de almacenamiento/origen, pero reduce el aislamiento del HTML cargado. La autonomía solo empieza cuando tú la activas.
